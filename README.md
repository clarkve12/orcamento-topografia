# Orçamento de Topografia — Clessiano Antunes

Calculadora de orçamentos para serviços de topografia e georreferenciamento (rural e urbano).

## O que calcula
- Deslocamento (combustível, desgaste e depreciação do veículo, pedágio, asfalto x terra)
- Equipe de campo (técnico, ajudantes, alimentação, hospedagem) com escolha automática entre ir e voltar ou pernoitar
- Depreciação dos equipamentos (2 RTK e drone)
- Horas de escritório, marcos, TRT (CFT) e taxas de terceiros
- Rateio de custos fixos, impostos, margem e valor mínimo (R$ 3.000 rural / R$ 1.200 urbano)
- Proposta em PDF e texto para WhatsApp

## Como publicar
Site estático: basta o `index.html`. No GitHub: Settings → Pages → Deploy from a branch → `main` / root.
